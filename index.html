✨ Code Your First Web Page!

Be creative. Try something new. Make it yours!

Welcome, Future Web Developer! 💻

Ready to turn your ideas into a real website? Follow these steps to build a page about your favorite animal. You will use HTML, CSS, and JavaScript.

No account or download is needed.

STEP 1

Open Web Maker 🌐

Open Web Maker in a new tab.

Find the HTML, CSS, and JavaScript editor panels. Your page preview should appear beside or below the editors.

Remember: HTML goes in the HTML panel, CSS goes in the CSS panel, and JavaScript goes in the JavaScript panel.

STEP 2

Add the HTML 🧱

HTML creates the content on your page. Select the starter code in Web Maker's HTML panel, then replace it with this code.

HTML code 
<h1>Welcome to My Website!</h1>
<p>Hi, I'm your name here and this is my first web page!</p>
<h2>My favorite animal is a cat</h2>

<img src="https://schertzanimalhospital.com/wp-content/uploads/2017/12/Schertz_iStock-590055188-1024x682.jpg" alt="A cute cat">

<p>I love learning web development because it's fun and creative!</p>
<button>Click me to change the background color!</button>

Make it yours: Replace "your name here" with your name. Keep the HTML code in the HTML panel.

STEP 3

Style Your Page 🎨

CSS controls how your page looks, including colors, fonts, image size, and button style. Paste this code into the CSS panel.

CSS code 
body {
    background-color: lightpink;
    font-family: "Comic Sans MS", sans-serif;
    text-align: center;
}

h1 {
    color: hotpink;
}

img {
    border-radius: 10px;
    width: 500px;
    max-width: 100%;
}

button {
    background-color: hotpink;
    color: white;
    border: none;
    padding: 10px 20px;
    border-radius: 8px;
}

button:hover {
    background-color: deeppink;
}

Experiment: Try changing lightpink to lightblue or lavender. What changes?

STEP 4

Make It Interactive ⚡

JavaScript makes your button do something when you click it. Paste this code into the JavaScript panel.

JavaScript code 
const button = document.querySelector("button");

button.addEventListener("click", function() {
    const randomColor = `hsl(${Math.floor(Math.random() * 360)}, 70%, 70%)`;
    document.body.style.backgroundColor = randomColor;
});
STEP 5

Test Your Website! 🚀

  1. Look at your live preview.
  2. Check that your heading, cat picture, and button appear.
  3. Click the button. The background should change color!
  4. If something does not work, check that each code section is in the correct panel.

🌟 Your Creative Challenge

Now make the page your own!

  • Change the heading color.
  • Choose a different background color.
  • Change the button text to something fun.
  • Find a picture of your favorite animal and use its image URL.

There is no single right design. Be creative and have fun!
